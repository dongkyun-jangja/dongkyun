# 데일리샷 DDMS 배송 기사 사용 매뉴얼

> **앱 이름**: DDMS (Dailyshot Driver Management System)
> **버전**: 1.0.1
> **배포일**: 2026-05-14
> **대상**: 신동주류 배송 기사님

---

## 0. 이 앱이 왜 다른가요? — 한 화면 요약

기존 종이 출고지·카카오톡 보고를 대체합니다. 핵심 변화 5가지:

| 기존 | DDMS |
|------|------|
| 종이 출고지에 매장·상품 적어 다님 | **앱에 오늘 매장 20곳·모든 상품이 미리 들어있음** |
| 매장마다 카톡으로 "○○ 완료"라고 보내야 함 | **사진 한 장 찍으면 완료 처리. 자동으로 다음 매장 안내** |
| 이슈 발생 시 매장명·상품 일일이 타이핑해 카톡 보고 | **"이슈 신고" 한 번 누르면 메시지 자동 작성 + 카톡 자동 열림** |
| 회수 상품을 기억해서 따로 처리 | **회수 상품·사유까지 한 화면에 표시. 누르면 끝** |
| 일 끝나고 전표 다시 정리 | **"오늘 전표 보기" 한 번 누르면 카톡으로 자동 공유** |

**핵심 약속**: 한 매장에 머무는 시간을 줄이고, 카톡 타이핑을 없애고, 손에 폰만 들고 한 손으로 다 처리할 수 있게 만들었습니다.

## 1. 처음 설치하기

### 1-1. 설치
1. 회사에서 받은 **다운로드 링크**를 안드로이드 브라우저(크롬·삼성인터넷)로 열기
2. APK 파일이 다운로드되면 → 알림 → **열기** 탭
3. "이 출처에서 앱 설치 허용" 안내가 나오면 → **설정** → **허용** → 뒤로 가기 → **설치**
4. **DDMS** 아이콘이 홈 화면에 추가됩니다

### 1-2. 첫 실행 — 권한 한 번만 허용하세요
- **카메라**: 배송 사진 찍을 때 사용. **반드시 허용** 필요
- **푸시 알림**: 배송 알림 받을 때 사용. 권장
- **카카오톡 연결**: 처음 카톡 보낼 때 한 번만 설정 (설정 → 카카오톡 연결)

> 💡 **만약 실수로 카메라 거부 누르셨다면?** → 매장 상세에서 "사진 촬영" 누르면 "설정 열기" 버튼이 나옵니다. 한 번 눌러서 카메라 허용해 주세요.

## 2. 하루 사용 흐름 — 시간순으로 따라하기

### 🌅 STEP 1. 출근 (06:00)

**앱 켜기** → 홈 화면에 다음이 보입니다:

```
강동규 기사님 👋
신동주류 · A코스
2026년 5월 14일

[📋 코스 미확정] ← 빨간 카드. 탭하세요
```

코스 미확정 카드를 누르면 **오늘 배송할 20곳의 매장 순서**가 나옵니다.
- 매장 순서가 어제와 다르면 ↑↓ 버튼 또는 카드 길게 눌러서 드래그
- 다 맞으면 하단 **"확정하기"** 버튼

확정하면 모달 창에 오늘 작업량이 한눈에 보입니다:
```
🚚 배송 코스 확정!
20 매장 · 138 박스 · 2 회수

[1번 블랙앤밀 스타카자점로 출발 →]   ← 바로 첫 매장으로 이동
[홈으로]                              ← 보조 (일반적으로는 안 누름)
```

### 🚗 STEP 2. 매장 도착 (06:30)

매장에 도착하면 자동으로 **매장 상세 화면**이 떠있습니다 (전 매장 완료 시 자동 이동).
처음이라면 홈에서 오렌지색 **"지금 가야 할 곳"** 카드를 누르세요.

매장 상세 화면 위에서부터:
1. **매장명·주소·전화번호** — 전화번호 누르면 즉시 통화
2. **노란 배송 메모** (있을 때만): "지하 냉장창고", "도어락 1234" 등
3. **배송 상품 목록** — 박스 수·개수·쇼핑백 수
4. **회수 상품 목록** (있을 때만, 파란 카드)
5. **특이사항** — 현장 메모 입력
6. 하단 **사진 촬영하기** 버튼

### 📸 STEP 3. 배송 사진 (06:45)

1. 매장 안에 상품 두고 → **사진 촬영하기** (큰 검정 버튼)
2. 사진 찍으면 미리보기 카드가 나타납니다
3. 잘 찍혔는지 확인. 흐리거나 어두우면 **다시 찍기** 가능
4. **쇼핑백이 있는 매장**이면 "🛍 쇼핑백 N개 포함 확인" 체크박스
5. 하단 **"배송 완료 확정"** 큰 검정 버튼

완료 처리되면:
- 🍞 토스트: `1/20 완료 · 다음 → 91전통 마니배분 서울점`
- 2~3초 후 **다음 매장 상세 화면으로 자동 이동**

> 💡 한 매장에서 평균 30초~1분이면 끝납니다.

### ↩️ STEP 4. 회수 상품 매장 (08:00, 60위치긴 서서울충점)

**배송 + 회수가 동시에 있는 매장**은:
1. 배송 사진 촬영 → 미리보기
2. **회수 상품 처리도 함께 해야 "배송 완료 확정" 버튼이 활성화됩니다**
3. 회수 상품 카드(파란색)에서 두 버튼 중 선택:
   - **🔵 회수 완료** — 회수 OK
   - **🔴 회수 미완료** — 사유 선택 popup

회수 미완료 popup의 4가지 사유:
- ⓘ 매장에 주류 없음 — 회수 대상 상품이 매장에 존재하지 않음
- ⓘ 매장 부재 — 점주/직원 부재로 회수 불가
- ⓘ 중복/오기입 — 회수 요청 자체가 중복 또는 오기입
- ⓘ 기타 — 직접 사유 입력

처리 후 "배송 완료 확정" 누르면 평소와 동일하게 다음 매장으로 이동합니다.

**회수만 있는 매장** (배송 X, 회수 O — 예: 찬라마이 슈로수파카점):
1. 사진 촬영 단계 없음
2. 바로 **회수 완료** 또는 **회수 미완료** 큰 버튼만 표시
3. 처리하면 토스트와 함께 다음 매장 자동 이동

### ⚠️ STEP 5. 이슈 발생 시

매장이 닫혀있거나, 점주가 거부하거나, 상품에 문제가 있는 경우:

1. 매장 상세 화면 하단의 **"이슈 신고"** 빨간 버튼
2. 안내 popup:
   ```
   ⚠️ 이슈 신고

   1. 이슈 메시지 클립보드 복사
   2. 채팅방 자동 오픈
   3. 붙여넣기 후 전송
   ```
3. **"신고 및 채팅방 열기"** 탭
4. 카카오톡 채팅방이 자동으로 열림 → **메시지 입력창에 길게 눌러 "붙여넣기"** → 전송

자동 작성되는 메시지 예시:
```
🚨 [이슈 신고] 60위치긴 서서울충점

배송 기사: 강동규 (신동주류 · A코스)
신고 시각: 오전 9:42

📍 매장
60위치긴 서서울충점
서울시 서초구 반포동 22-1
☎ 02-3456-7890

📦 배송 상품
• 바크스 룸 세이카스코 (750ml) — 1박스 (6개)
• 오스카 로디스 (750ml) — 1박스 (12개)

⚠️ 담당자 확인 및 처리 부탁드립니다.

— DDMS 자동 알림
```

### 🎉 STEP 6. 하루 종료 (14:30)

마지막 매장 완료하면 자동으로 홈 화면이 뜨고 **축하 팝업**:
```
🎉
오늘 배송 모두 완료!
신동주류 · A코스

[20 매장]  [138 박스]  [2 회수]  [1 이슈]

정말 수고하셨습니다 👏
[확인]
```

### 💬 STEP 7. 전표 카톡 공유

홈 화면 → **"오늘 전표 보기"** → 화면 우측 상단 💬 또는 하단 **"카카오톡 채팅방으로 공유"** 큰 노란 버튼

자동으로:
1. 전표 텍스트가 클립보드에 복사됨
2. 카카오톡 채팅방이 열림
3. 메시지창에서 **길게 눌러 "붙여넣기"** → 전송

전표 예시 (요약):
```
[DDMS 배송 전표] 2026년 5월 14일 (목)
신동주류 · A코스 · 강동규 기사
전송: 14:35

━━ 요약 ━━
✅ 19곳 완료  ⚠️ 1곳 이슈
📦 총 138박스 · 20종 · 20개 매장

━━ 이슈 신고 ━━
⚠️ 60위치긴 서서울충점

━━ 매장별 내역 ━━
1. ✅ 블랙앤밀 스타카자점 ◆ 07:42
   ◆청하 (300ml) 12박스 - 360개 🛍3개
   ...
```

## 3. 화면별 자세히 보기

### 3-1. 홈 (대시보드)

기사님이 가장 자주 보는 화면. 위에서부터:

| 영역 | 내용 |
|------|------|
| 오렌지 헤더 | "강동규 기사님 👋" · 신동주류 · A코스 · 날짜 |
| 알림·설정 버튼 (우측 상단) | 빨간 점 = 설정 필요 (한 번에 1개만 표시 — 우선순위 적용됨) |
| **진행률 카드** | `19/20 곳` 큰 숫자 + 진행률 바. 카드 전체 탭하면 배송 목록 화면으로 |
| stats 줄 | `완료 19 · 정정 1·🛍 1   대기 0   이슈 1` — 정정/🛍는 수량 불일치·쇼핑백 부족 상품 수 |
| 🎉 전체 완료 배너 | 모든 매장 끝났을 때 |
| **다음 배송지 카드** | 오렌지색, 가장 큼. 탭하면 매장 상세로 |
| ⚠️ 이슈 신고 카드 | 이슈 발생한 매장만. 탭하면 매장 상세로 |
| 완료한 배송 카드 | 완료 매장 목록. **"취소" 버튼은 두 번 눌러야 작동** (실수 방지) |
| **오늘 전표 보기** 버튼 | 카카오톡 공유 화면으로 |
| 팀 채팅방 (노란 버튼) | 배송팀 카카오톡 채팅방 즉시 열기 |

#### "취소" 버튼 두 번 누르는 이유
한 번 누르면 → 버튼이 빨갛게 **"정말?"** 로 변합니다. 2.5초 안에 한 번 더 누르면 취소 popup 열림. 실수로 한 번 눌렀어도 가만히 두면 2.5초 뒤 원래대로 돌아옵니다. 안전장치입니다.

### 3-2. 배송 목록 (탭에서 "목록")

오늘 배송할 모든 매장을 순서대로 보여줍니다.

| 기능 | 사용 방법 |
|------|----------|
| 매장 카드 탭 | 매장 상세 화면으로 이동 |
| 매장 순서 변경 | ① 카드 길게 누르면 드래그 가능 ② 카드 우측 **≡** 아이콘 한 번 탭 → 드래그 ③ 하단 **↑위로 ↓아래** 버튼 |
| 진행률 바 | 상단에 항상 표시 |
| 매장 카드 정보 | 매장명·상태·전화·주소·메모·상품 칩(2개+더보기)·쇼핑백 칩·회수 칩(파란 띠) |
| 안내 배너 dismiss | "≡ 탭 또는 카드 길게 누르면 드래그..." 안내가 익숙해지면 우측 × 한 번 누르면 영구 사라짐 |

> 💡 **자동 스크롤**: 한 매장 완료한 뒤 목록으로 돌아오면 **다음 미완료 매장 위치로 자동 스크롤**됩니다. 위로/아래로 따로 찾을 필요 없음.

### 3-3. 매장 상세 (가장 자주 쓰는 화면)

화면 위에서부터:

1. **헤더** — 매장명 + 상태(대기/완료/이슈) + 우측 공유 아이콘 (배송팀 단톡방에 매장 정보 공유)
2. **진행률 스트립** — "3번째 배송지 · 2/20 완료"
3. **🟧 배송 메모 배너** (있을 때만) — 노란 배경. 매장의 특별 주의사항
4. **매장 정보 카드** — 주소·전화. 전화 누르면 즉시 통화
5. **배송 상품 섹션**
   - 각 상품: 썸네일 이미지 + 상품명 + 코드 + 박스/개수 + 🛍 쇼핑백
   - ◆ 블랙 마크 = 블랙멤버십 상품 (우선 처리 권장)
   - 상품 이미지 탭 → 큰 화면으로 확대
6. **회수 상품 섹션** (있을 때만, 파란 카드) — 사유/예정조치/출고일이 칩으로 표시됨
7. **회수 메모 추가** (선택) — 회수 관련 기사 비고
8. **특이사항** — 매장에서 발견한 메모. 탭해서 작성
9. **사진 미리보기 카드** (촬영 후) — 사진 확인, 다시 찍기, 추가 촬영(최대 3장)
10. **하단 검정 버튼** — `사진 촬영하기` → `배송 완료 확정`

#### 수량 불일치 기록 (상품이 부족하거나 더 갔을 때)

상품 행 안 **"수량 불일치 기록"** 작은 텍스트:
1. 탭 → 인라인 입력창
2. 실제 수량 입력 (예: 요청 6개 → 실제 5개로 입력) → 확인
3. 상품 행이 **빨간색**으로 표시되고, 매장 카드에 ⇄ 수량 불일치 태그 표시
4. 잘못 입력했으면 "수정" 또는 "초기화"

#### 쇼핑백 부족 기록 (쇼핑백을 다 못 줬을 때)

쇼핑백이 있는 상품(`🛍 N개` 표시)에서 **"쇼핑백 부족 기록"** 작은 텍스트:
1. 탭 → 인라인 입력 "실제 쇼핑백 N/M개"
2. 실제 전달한 수량 입력 → 확인
3. 🛍 chip이 빨갛게 변하고 `🛍 1/2개` 표시
4. 사진 미리보기 영역의 체크박스도 자동으로 ⚠️ 부족 상태로 변환

> 💡 **수량 불일치·쇼핑백 부족은 이슈가 아닙니다.** 배송 완료로 분류되되 본사 정산용으로만 기록됩니다. 따로 카톡 보낼 필요 없습니다 — 오늘 전표에 자동으로 들어갑니다.

#### 배송 완료 게이팅
회수 상품이 있는 매장에서 **회수 처리를 안 하면 "배송 완료 확정" 버튼이 흐릿하게 비활성화**됩니다. 아래에 안내 문구: "회수 상품을 먼저 처리해 주세요". 회수 완료 또는 회수 미완료 둘 중 하나 처리하면 활성화됩니다.

#### 회수 완료/미완료 취소

회수 완료/미완료 처리한 뒤 다시 되돌리고 싶을 때:
1. 회수 카드 상단의 상태 chip 옆 **"↶ 취소"** 작은 버튼
2. Popup에서 사유 입력 → "완료 취소" 또는 "미완료 취소"

### 3-4. 오늘 전표

하루 정리 + 카톡 공유 전용 화면.

| 영역 | 내용 |
|------|------|
| 전표 헤더 | 날짜·기사·도매사·코스 + "코스 확정됨" 배지 + 확정 시각 |
| 총계 카드 | 완료·이슈 chip + 박스·종류·매장·수량불일치·쇼핑백부족 stats |

## 4. 자주 묻는 질문 (FAQ)

### Q1. 사진을 잘못 찍었어요. 다시 찍을 수 있나요?
**A.** 네. 사진 미리보기 카드의 사진 우측 상단 **×**를 누르면 삭제됩니다. 또는 미리보기 아래의 **"다시 찍기"** 버튼.

### Q2. 배송 완료를 잘못 눌렀어요.
**A.** 홈 화면 → 완료한 배송 목록에서 해당 매장의 **"취소"** 버튼 두 번 누르세요 → 사유 입력 popup → "완료 취소". 매장이 다시 "대기" 상태로 돌아옵니다.

### Q3. 회수 미완료 사유에 우리 매장 상황이 없어요.
**A.** **"기타"** 선택하시고 아래 메모 입력란에 상황 직접 입력 (필수).

### Q4. 운전 중 다음 매장 순서를 바꿔야 해요.
**A.** 차 세우신 뒤 → 배송 목록 화면에서 해당 매장을 길게 누르거나 ↑↓ 버튼으로 순서 조정. 운전 중에는 안전을 위해 사용하지 마세요.

### Q5. 카톡이 자동으로 안 열려요.
**A.** 폰에 카카오톡이 설치되어 있고 로그인되어 있어야 합니다. 처음 사용 시 **설정 → 카카오톡 연결**에서 사용할 채팅방을 한 번 등록해 주세요. 빨간 점이 설정 아이콘에 떠있으면 등록이 필요한 상태입니다.

### Q6. 카메라 권한을 처음에 거부했어요.
**A.** 사진 촬영 버튼 누르면 **"카메라 권한 필요"** Alert이 뜹니다. **"설정 열기"** 누르면 폰 설정 → 카메라 → 허용 한 번에 됩니다.

### Q7. 매장 상세에서 "지금 가야 할 곳"이 아닌 다른 매장으로 먼저 가고 싶어요.
**A.** 배송 목록 화면에서 다른 매장 카드를 직접 탭하시면 됩니다. 순서를 영구 변경하려면 드래그 또는 ↑↓ 버튼 사용.

### Q8. 오늘 전표를 다시 보낼 수 있나요?
**A.** 네. 홈 → "오늘 전표 보기" → 카카오톡 공유 버튼 → 채팅방에 다시 붙여넣기. 횟수 제한 없음.

### Q9. 블랙멤버십 ◆ 상품은 뭔가요?
**A.** 본사 블랙멤버십 가입 고객의 상품으로, 매장에서도 별도 보관·우선 안내해야 합니다. ◆ 표시되어 있으면 매장 직원에게 강조해서 인계해 주세요.

### Q10. 한 손으로 사용해도 되나요?
**A.** 네. 주요 버튼들(사진 촬영, 완료 확정, 회수 처리)은 한 손 엄지로 닿을 수 있는 큰 크기로 만들었습니다. 햇빛에서도 잘 보이도록 텍스트도 굵게 했습니다.

## 5. 문제 해결 가이드

| 증상 | 해결 방법 |
|------|----------|
| 앱이 켜지지 않음 | 폰 재시작 → 다시 실행 |
| 사진이 안 찍힘 | 카메라 권한 확인 (설정 → 앱 → DDMS → 권한 → 카메라 → 허용) |
| 진행률이 이상함 | 홈 → 진행률 카드 탭해서 배송 목록 확인 |
| 잘못된 매장으로 이동 | 헤더 왼쪽 **"< 목록"** 으로 돌아가서 올바른 매장 직접 선택 |
| 데이터가 사라진 것 같음 | 앱이 자동 저장합니다. 폰 재시작 후 다시 열어보세요. 그래도 안 되면 본사 연락 |
| 카톡 공유 시 텍스트가 안 붙음 | 카톡 메시지 입력창에서 **꾹 누르기 → 붙여넣기** 선택 |
| 글씨가 작아 안 보임 | 폰 설정 → 디스플레이 → 글꼴 크기 키우기 (이 앱은 폰 설정 반영) |

## 6. 핵심 팁 (한 줄 요약)

✅ 사진 한 장이면 충분합니다. 잘 보이게만 찍으세요.
✅ 완료 버튼 누르면 **자동으로 다음 매장 안내**됩니다. 매번 목록 안 들어가도 됩니다.
✅ 회수 매장은 **배송과 함께 한 번에 처리**하세요. 둘 다 끝나야 다음으로 넘어갑니다.
✅ 이슈 상황은 **"이슈 신고"** 버튼만 누르면 메시지가 자동 작성됩니다. 타이핑 X.
✅ 일 끝나면 **"오늘 전표 보기" → 카톡 공유** 한 번이면 보고 끝.
✅ 수량 부족·쇼핑백 부족은 **이슈가 아닙니다.** 그 자리에서 기록만 하면 본사에서 처리합니다.
✅ 모든 텍스트는 **꾹 누르거나 한 번 누르면 됩니다.** 두 번 눌러야 작동하는 버튼은 안전장치이니 그대로 두세요.
