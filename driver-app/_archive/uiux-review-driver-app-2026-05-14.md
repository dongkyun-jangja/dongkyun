# Driver-App UI/UX 점검 보고서

> **점검 대상**: 데일리샷 driver-app (React Native, 배송 기사용)
> **점검 일자**: 2026-05-14
> **점검 프레임**: B.I.A.S 휴리스틱 → Peak-End 저니맵 → 합성 페르소나 압박 시뮬레이션 (3단계 누적)
> **참조 스킬**: product-psychology-for-vibe-coding, korean-synthetic-consumer

---

## Executive Summary

이 앱은 **B2B 작업 도구로서 매우 잘 설계**되어 있습니다.

| 강점 | 약점 |
|------|------|
| 진행률 가시화·다음 액션 안내 명확 | **회수와 배송의 UX 일관성 비대칭** (가장 큰 결손) |
| 카톡 자동 복사·열림 등 마찰 제거 잘됨 | 야외 직사광 환경에서 작은 보조 텍스트 가독성 |
| 색상 코드(pending·delivered·issue) 일관 | 한 손·시간 압박 시 일부 인터랙션 거침 |
| 이슈 처리 동선이 매우 매끄러움 (Peak 잘 설계됨) | 신규 사용자 학습 곡선 보조 부족 (dismiss·tooltip) |

이미 +3 Peak 두 곳(매장 완료 토스트·하루 종료 팝업)이 잘 잡혀 있고 End(전표 공유)도 좋음. **저점(회수 처리 후) 평탄화** + 햇빛 가독성 보강이 핵심 개선 방향.

## 점검 프레임 — 이 앱 특성 반영

일반 소비자 앱과 달리 driver-app은 **B2B 작업 도구**라 표준 B.I.A.S에서 가중치를 조정했습니다:

| 단계 | 일반 앱 | 이 앱 적용 |
|------|---------|-----------|
| **B**lock | 광고처럼 안 보이게 | 동시에 화면에 떠있는 정보 7±2 이하, 햇빛에서 핵심 정보 가독성 |
| **I**nterpret | 혜택 먼저 | "지금 내가 뭘 해야 하나" 1초 안에 인지, 상태 vs 액션 시각적 분리 |
| **A**ct | 마찰 최소화 + 넛지 | 한 손·장갑 낀 손가락·탭 영역 ≥44pt·시간 압박 견디는 마찰 0 |
| **S**tore | 긍정 기억 | 매 매장 처리 직후 "확실히 됐다" 확신, 다음 액션 자동 안내 |

환경 변수 (BMAP의 Ability 축):
- 사용자: 50대, 8년차, 시력 약함, 한 손 사용 빈번
- 환경: 야외, 직사광, 매장 진입로, 시간 압박(분 단위 진행)
- 디바이스: 자기 폰, 보호 케이스로 화면 가장자리 닿기 어려움

# 1단계 — B.I.A.S 휴리스틱 점검

각 화면을 4축(Block/Interpret/Act/Store)으로 점검. 우선순위: ⭐⭐⭐ 즉시 / ⭐⭐ 권장 / ⭐ 모니터링.

## Dashboard (홈)

정보 위계는 명확, 단 작은 인터랙티브 요소들이 야외 환경에서 약점.

| 축 | 발견 사항 | 우선순위 |
|---|----------|---------|
| B | 헤더의 알림·설정 버튼에 빨간 도트가 동시에 뜰 수 있음 → 어느 게 시급한지 모름 | ⭐⭐ |
| B | 다음 배송지 오렌지 카드 = 시각적 1순위 ✅ | — |
| I | 진행률 카드 하단 "완료 19 / 대기 0 / 이슈 1" 라인이 작음 → 햇빛 가독성 떨어짐 | ⭐⭐ |
| A | 완료한 배송의 인라인 "취소" 버튼이 시각·매장명과 너무 가까움 → 오탭 위험 | ⭐⭐⭐ |
| A | 헤더 알림·설정 아이콘 ~32×32, hitSlop은 있지만 한 손으로 닿기 어려움 | ⭐ |
| S | 전체 완료 시 🎉 팝업, 진행률 바 채움 → Store 피드백 충실 ✅ | — |
| S | 배송 완료 취소 popup이 사유 필수 → 실수 차단 + 감사 추적 ✅ | — |

## Deliveries (목록)

매장 카드 정보 밀도 높음. 베테랑엔 좋지만 신규 사용자엔 학습 비용.

| 축 | 발견 사항 | 우선순위 |
|---|----------|---------|
| B | 한 카드에 요소 9~11개 → 인지 부하 | ⭐⭐ |
| B | 안내 배너 베테랑엔 영구 노이즈 → dismiss 옵션 없음 | ⭐⭐ |
| I | 회수 배지가 다른 칩과 비슷한 톤 → 별도 액션 필요한 정보인데 묻힘 | ⭐⭐ |
| A | ↑↓ 버튼이 카드 하단 작은 영역 → 한 손 엄지로 오탭 잦을 듯 | ⭐ |
| A | 드래그 핸들 탭 → 즉시 드래그 ✅ | — |
| S | 한 매장 완료 후 목록 복귀해도 자동 스크롤 없음 → 다음 pending 매장 찾기 위해 사용자가 직접 스크롤 | ⭐⭐⭐ |

## Store Detail (매장 상세) — 가장 복잡, 핵심 화면

정보 분리 잘됨. 하지만 **회수와 배송의 UX 일관성 부족**이 가장 큰 약점.

| 축 | 발견 사항 | 우선순위 |
|---|----------|---------|
| B | 화면 세로 길이 매우 큼 (7~10개 섹션). 회수 칩 3개로 시각 복잡 | ⭐⭐ |
| B | 블랙 안내 배너 모든 매장에 자주 떠서 습관화로 무시 가능 | ⭐ |
| I | 회수 카드 파란 보더 + 좌측 dot 파랑 → 배송과 명확히 구분 ✅ | — |
| I | 회수 완료 chip의 "취소" 버튼 (위·아래 두 곳) → 발견성 좋아짐 ✅ | — |
| A | **회수 완료 후 자동 다음 매장 이동 없음** — 배송 완료는 있는데 회수만 끝나면 사용자가 직접 뒤로 가야 함. UX 일관성 ❌ | ⭐⭐⭐ |
| A | 사진 촬영 권한 거부 시 Alert만 표시 → 설정 deep link 없음 | ⭐⭐ |
| A | 배송 완료 게이팅 (회수 미처리 시 비활성) + 파란 안내 ✅ | — |
| S | 배송 완료 시 토스트 + 다음 매장 이동 ✅ | — |
| S | **회수 완료 시 토스트 없음** → chip만 색 바뀜. "확실히 됐다" 확신 약함 | ⭐⭐⭐ |
| S | 이슈 신고 → 메시지 자동 복사 + 카톡 자동 열림 ✅ Peak 잘 설계됨 | — |

## Today Summary (전표)

그룹화·공유 흐름 매우 잘됨. 매장 카드 정보 밀도가 트레이드오프.

| 축 | 발견 사항 | 우선순위 |
|---|----------|---------|
| B | 총계 카드 한 행에 4개 지표(박스/종/매장/수량불일치) → 햇빛에서 숫자 분간 어려움 | ⭐⭐ |
| B | 매장 카드 정보 매우 밀집 — 정독은 어렵고 훑기 용도 | ⭐ |
| I | 그룹화: 이슈 → 미완료 → 완료 순서 → 우선순위 명확 ✅ | — |
| I | 회수 라벨 "회수 미완료 · 매장 부재" enum 사람말로 표시 ✅ | — |
| A | 매장 카드 자체 탭 안 됨 — deliveries에서는 탭하면 상세 가는데 여기선 안 됨. 일관성 ❌ | ⭐⭐ |
| A | 카톡 공유 버튼 헤더·하단 양쪽 진입점 ✅ | — |
| S | 복사 완료 토스트 + 채팅방 자동 열림 → 마찰 0, Peak 좋음 ✅ | — |

# 2단계 — Peak-End 저니맵

## 전체 여정

| # | 단계 | 사용자 행위 | 시스템 응답 | 감정 (-3~+3) |
|---|------|-----------|-----------|:-:|
| 1 | 첫 진입 | 앱 열기 | 강동규 기사님 + 코스 미확정 카드 | +1 |
| 2 | 코스 확정 | 매장 순서 확인 + 확정 버튼 | "코스 확정됨" 배지 | 0 |
| 3 | 첫 매장 이동 | 다음 배송지 카드 탭 | 매장 상세 진입 | +1 |
| 4 | 매장 도착 | 주소·메모·상품 확인 | 정보 카드 표시 | 0 |
| 5a | **배송 액션** | 사진 → 미리보기 → 완료 확정 | 🍞 토스트 + 자동 다음 매장 | **+2** ✨ |
| 5b | **회수 액션 (전용)** | 회수 완료 버튼 탭 | chip만 색 바뀜, 머무름 | **0** ⚠️ |
| 5c | **회수 액션 (배송+회수)** | 두 액션 다 처리 후 확정 | 토스트 + 이동 | **+2** ✨ |
| 6 | 이슈 발생 | "이슈 신고" → 확인 popup | 메시지 자동 복사 + 카톡 자동 열림 | **+2** ✨ |
| 7 | 반복 (4~5) | 19곳 매장 처리 | 진행률 채워짐, 매장 자동 전환 | +1 |
| 8 | **하루 종료** | 마지막 매장 완료 | 🎉 전체 완료 팝업 | **+3** ✨✨ |
| 9 | 전표 공유 | "오늘 전표 보기" 탭 | 전표 자동 복사 + 카톡 열림 | **+3** ✨✨ |

**현재 End**: +3 (전표 공유 카톡 자동 열림) — 매우 좋은 마무리
**현재 최고 Peak**: +3 (하루 종료 🎉 팝업) — 잘 설계됨
**저점**: 5b (회수 전용 매장 처리 후) — 피드백·전환 부재

## Peak-End 4대 전략

### 1) Repair the Worst (저점 보수) — 최우선

| 저점 지점 | 현재 문제 | 보수 제안 |
|-----------|-----------|----------|
| 5b 회수 전용 매장 처리 후 | chip 색만 바뀌고 머무름. 배송 액션의 토스트·자동 이동과 비대칭 | 회수 완료 시 토스트 "회수 완료! 다음 매장으로 →" + 자동 이동 |
| 2 코스 확정 단계 | "확정" 후 별다른 감흥 없음 | "오늘 19곳 · 총 138박스, 출발 준비 완료!" 가시화 |
| 이슈 발생 후 회수 전용 매장 | 회수 미완료 처리 후 dashboard에서 이슈 카드에만 표시 — 너무 강한 부정 신호 | "공유 완료 → 본사가 처리 중" 톤 전환 |

### 2) Elevate the Peak (정점 강화)

| 정점 | 현재 | 추가 강화 |
|------|------|----------|
| 5a 배송 완료 토스트 | "완료! 다음 배송지로 →" | 진행도 가시화 ("19곳 중 7번째 완료 · 다음 →") |
| 8 하루 종료 팝업 | 🎉 + "정말 수고하셨습니다" | 본인의 노력 가시화 ("오늘 139박스 · 매장 20곳") |
| 9 전표 공유 | 자동 복사 + 카톡 열림 | "오늘 전표 전송 완료. 푹 쉬세요 ☕" 같은 케어 멘트 |

### 3) Improve Transitions (전환 명확화)

| 전환 지점 | 현재 | 개선 |
|----------|------|------|
| 코스 확정 → 첫 배송 | dashboard 거쳐 "지금 가야 할 곳" 카드 탭 | 코스 확정 직후 "첫 매장으로 바로 출발" CTA 직접 노출 |
| 매장 완료 → 다음 매장 (회수 전용) | 머무름 | 토스트 + 자동 이동 |
| 이슈 신고 → 카톡 열림 → 앱 복귀 | 카톡으로 나갔다가 안 돌아옴 | 카톡에서 복귀 시 "이슈 처리되었나요?" 확인 chip 일시 노출 |

### 4) Reorder Steps (단계 재배치)

| 항목 | 현재 순서 | 제안 |
|------|----------|------|
| 매장 상세 화면 섹션 순서 | 매장정보 → 배송상품 → 회수상품 → 특이사항 → 사진 → 하단바 | 매장에 회수만 있으면 회수를 위로, 배송만 있으면 배송을 위로 |

# 3단계 — 합성 페르소나 압박 시뮬레이션

## 페르소나: 강동규 (55세, 신동주류 8년차)

| 속성 | 값 |
|------|-----|
| 경력 | 8년차 배송 기사 (디지털 도구 익숙도 中) |
| 시력 | 노안 시작 (돋보기 미사용 시 작은 글씨 흐릿) |
| 손 | 두꺼움. 운전 장갑 끼고 짐 운반 |
| 환경 | 야외, 직사광, 한 손 빈번, 시간 압박 (5분 단위) |

## 시나리오 워크스루 — 실제 하루 시뮬레이션

20개 매장 코스(회수 매장 2곳 포함) 기준.

| 단계 | 마찰 | 심각도 |

| 사진 권한 거부 시 복구 | Alert만 + 설정 deep link 부재 | 🔴 ⭐⭐⭐ |
| mock photoUris[0] 미리 박혀있음 | 첫 진입 시 "이미 누가 찍어놨나?" 혼란 | 🟡 (시연용 주의) |
| 첫 회수 매장의 칩 3개 | "본사가 정한 거구만" 인지 시간 1초 | 🟢 |
| 회수 완료 후 chip만 바뀜 | "이게 끝? 다음 매장 가도 되나?" | 🔴 ⭐⭐⭐ |

## 박지훈 (32세, 1년차 신규) 시뮬 — 핵심만

| 단계 | 신규 사용자 마찰 |
|------|----------------|
| 코스 확정 | "확정 안 하면 뭐가 안 되지?" 학습 필요 — 카드의 안내 텍스트로 도움 ✅ |

## 시연 직전 적용 권장 (최소 3개)

시연 임박해 1~2시간만 작업 가능하면 **이 3개**만 처리해도 가장 큰 인상 차이가 생깁니다:

1. **A1** — 회수 완료 시 토스트·자동 이동
2. **D5** — 배송 완료 토스트에 진행도 가시화
3. **D3** — 하루 종료 팝업에 본인 성과 가시화

이유:
- A1은 1·2·3단계에서 3회 재확인된 가장 큰 일관성 결손
- D5·D3은 작업 분량 5~10줄로 Peak 두 곳을 직접 강화
- 시연자가 가장 강렬한 인상을 받는 순간이 첫 매장 완료 직후와 하루 종료라 ROI가 최대
